# Capital Parking — respaldo

Esta carpeta es una copia independiente de respaldo creada para evitar depender únicamente del ChatGPT Site.

## Reglas incluidas
- Tolerancia de 5 minutos antes de cobrar la siguiente hora/fracción.
- Opción “Salió sin estacionarse” con cobro $0 y nota.
- Corrección manual de hora real de salida.
- Si la hora es corregida, se solicita motivo.
- Se conserva la hora real de salida y la hora de cierre del sistema para auditoría.
- Datos guardados localmente en el navegador mediante localStorage.
- Exportación manual del historial a JSON.

## Importante
Esta versión es un respaldo funcional reconstruido. No es una copia del código fuente original oculto del chatgpt.site.
